# BREACH — Cybersecurity Escape Room

A browser-based cybersecurity investigation game for high school and dual-credit students.

## Project goals

- One connected incident told through five missions.
- Three difficulty paths: Rookie Investigator, Security Analyst, and Incident Commander.
- Interactive simulated evidence, systems, logs, email, and network artifacts.
- Browser-only student experience; no installs or real-world system access.
- Designed for GitHub and Vercel deployment.

## Missions

1. The Infiltration — phishing, social engineering, and malware.
2. The Impostor — certificates, PKI, and trust.
3. Hidden Evidence — steganography, cryptography, and digital forensics.
4. Network Under Attack — packets, network defense, and lateral movement.
5. Incident Response — risk, containment, and recovery.

## Development

This project uses Next.js, React, and TypeScript.

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the application.

## Safety

All organizations, identities, messages, and evidence in the game are fictional. The game is a controlled educational simulation and does not interact with live systems.
